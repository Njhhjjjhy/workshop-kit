設計與 AI，動手做

Design and AI, hands on

五個回合。每一個回合，我先說，再示範，然後換你做。每一段都有複製按鈕，貼到你的 Claude Code 裡面。

Five rounds. Each one: I say it, I show it, then you do it. Every block has a copy button. Paste it into your own Claude Code.

在你自己的專案資料夾裡打開 Claude Code，不要在桌面。它會跳出視窗問你可不可以寫檔案，按同意。

Open Claude Code inside your own project folder, not on the Desktop. It will ask permission to write files. Say yes.

回合 1 · 它是嬰兒 Round 1 · It is a baby

讓它先問你，而不是先猜

Make it ask you instead of guessing

做完你會有：一個 ask-me 技能，存在你自己專案的 .claude/skills/ 裡面。以後每次工作前先叫它。

You walk away with: an ask-me skill, saved in your own project at .claude/skills/. You call it before every job from now on.

在這個資料夾的 .claude/skills/askme/ 裡面建立一個 SKILL.md。

這個技能的用途是：在我給你工作之前，先用選擇題問我不清楚的地方。

內容要寫：
一次只問一件事，用簡單的話，用選擇題。
只問設計上的選擇，絕對不要問我「什麼時候要」或「要先做哪一個」。
問到你有把握可以直接做為止，不要因為怕問太多就停。
不要問我技術決定，那是你自己判斷。

寫完以後告訴我檔案在哪裡，還有怎麼呼叫它。全部用繁體中文寫。
Create a SKILL.md at .claude/skills/askme/ in this folder.

What this skill is for: before you give me work, ask me about anything unclear, as multiple choice.

Write into it:
Ask one thing at a time, in plain words, as multiple choice.
Ask only about design choices. Never ask me when something is due or which item to do first.
Keep asking until you can build without guessing. Do not stop because you think you have asked too many.
Never ask me technical decisions. Those are yours to make.

When it is written, tell me where the file is and how to call it.
回合 2 · 規則先給 Round 2 · Rules first

把你的規則寫成檔案

Put your rules in files

做完你會有：一個 docs/design-rules/ 資料夾。一個檔案管一件事。人會忘記，檔案不會。

You walk away with: a docs/design-rules/ folder. One file owns one thing. People forget. A file does not.

先用剛才的 askme 技能問我三個問題，問我的產品該有什麼感覺。

然後在這個資料夾建立 docs/design-rules/，裡面四個檔案：

brand.md 管顏色。每個顏色一個名字、一個色碼、一個 token 名稱，寫成表格。
type.md 管字。字體、大小的級距、行高。
spacing.md 管間距。一個基準步階，所有數值都是它的倍數，寫成表格。
motion.md 管動態。時間長度和曲線。

規則：每一個事實只能有一個檔案管。每個檔案開頭要寫「這個檔案管什麼」。
不要寫形容詞，寫數值。沒有數值的就來問我，不要自己編。

寫完告訴我每個檔案管什麼，一句話。全部用繁體中文寫。
First use the askme skill you just wrote. Ask me three questions about how my product should feel.

Then create docs/design-rules/ in this folder, with four files:

brand.md owns colour. Every colour gets a name, a hex and a token name, in a table.
type.md owns type. Families, the size scale, line heights.
spacing.md owns spacing. One base step, every value a multiple of it, in a table.
motion.md owns motion. Durations and curves.

Rules: one fact is owned by exactly one file. Each file opens by stating what it owns.
Write numbers, not adjectives. If you do not have a number, ask me. Never invent one.

When done, tell me what each file owns, one line each.
回合 3 · 感覺變系統 Round 3 · Feeling becomes a system

從規則做出東西

Build from the rules

做完你會有：三個版本的卡片，每一個值都來自你剛才寫的規則，沒有一個是手寫的。

You walk away with: three versions of a card, every value coming from the rules you just wrote, none of them typed by hand.

照著 docs/design-rules/ 裡面的規則，幫我做三個版本的卡片，放在同一個檔案裡並排顯示。

我的產品是：（在這裡寫你的產品，一兩句就好）

每一個顏色、大小、間距都要從規則檔案來，不可以手寫數字。
三個版本要在結構上不一樣，不是只有顏色不一樣。

做完告訴我每個版本用了哪幾條規則，還有檔案的完整路徑。
Using the rules in docs/design-rules/, make three versions of a card, side by side in one file.

My product is: (write your product here, a sentence or two)

Every colour, size and spacing value must come from the rule files. Never type a number by hand.
The three versions must differ in structure, not just colour.

When done, tell me which rules each version used, and the full path to the file.
回合 4 · 它會說謊 Round 4 · It lies

問它怎麼檢查的

Ask it how it checked

做完你會知道：「做好了」不是證據。問兩次，看它改不改口。

You walk away knowing: "done" is not proof. Ask twice and watch whether the story changes.

你剛才說做好了。你怎麼檢查的？一步一步說。

哪些是你真的執行過或打開看過的，哪些是你推測的？分開列出來。
You said it was done. How did you check? Step by step.

Which parts did you actually run or open and look at, and which did you infer? List them separately.
你有加任何我沒有給你的東西嗎？
Did you add anything I did not give you?
你確定嗎？
Are you sure?
回合 5 · 品味是你的 Round 5 · Taste is yours

說出哪裡不對，然後叫它修

Say what is wrong, then have it fixed

做完你會知道：AI 給你的是平均。差別是有一個人說不夠好。不要說「比較好」，說「這個標題和價格在打架」。

You walk away knowing: what AI gives you is the average. The difference is a person saying not good enough. Do not say "better". Say "this heading and this price are fighting".

我看了，這裡不對：（用你自己的話說，越具體越好。例如：標題和價格在打架、第二張卡片的留白和第一張不一樣、按鈕看起來不像可以按）

照我說的修，只修我說的地方。修完告訴我你改了哪幾個值，還有那些值從哪一條規則來。
I looked at it. This is wrong: (say it in your own words, as specific as you can. For example: the heading and the price are fighting, the second card's whitespace does not match the first, the button does not look pressable)

Fix what I said, and only what I said. Then tell me which values you changed and which rule each one came from.

先給規則，再給工作。

Rules first, then the work.
